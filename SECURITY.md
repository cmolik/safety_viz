# Security Policy

## Supported versions

Only the latest release (the `main` branch and the most recent tagged version) receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately via [GitHub's private vulnerability reporting](https://github.com/cmolik/safety_viz/security/advisories/new) — do not open a public issue.

Note that this repository contains only the frontend. Issues concerning data storage or the REST API belong to the CL01000136-V2 backend ("Knowledge base") and its maintainers.
